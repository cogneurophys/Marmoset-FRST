# Marmoset-FRST
Feature rule switching task (FRST) is a touchscreen task for marmosets. Presented with 2 coloured shapes, they discover the correct feature (a shape or a colour) and choose it consistently, before the target feature-rule is switched and they must re-discover the new rule. We simulated their performance with Feature Reinforcement Models. 

Citation: Repeated within-session rule switching in the marmoset: a paradigm for tracking the dynamics of cognitive flexibility
Marium H. Alvi, Ryley P. Nathaniel, Karmen Rai, Liya Ma
bioRxiv 2026.07.31.740852; doi: https://doi.org/10.64898/2026.07.31.740852
